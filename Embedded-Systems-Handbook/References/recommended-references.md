# Recommended References for Embedded Systems Engineers

## STM32 Documentation

1. **STM32 Reference Manuals** - Official ARM Cortex-M documentation
   - RM0090: STM32F4 series
   - RM0368: STM32F7 series
   - RM0433: STM32H7 series

2. **STM32 Datasheets** - Electrical characteristics, pinouts
   - Available on ST.com for each specific part number

3. **STM32CubeMX** - Configuration tool and code generator
   - https://www.st.com/en/development-tools/stm32cubemx.html

---

## ARM Documentation

1. **ARM Cortex-M Technical Reference Manuals**
   - Cortex-M4: DUI0553
   - Cortex-M7: DUI0646

2. **ARM Architecture Reference Manual**
   - Comprehensive guide to ARM instruction set

3. **CMSIS Documentation**
   - Common Microcontroller Software Interface Standard

## Coding Standards

1. **MISRA C:2012** - Guidelines for safety-critical systems
   - Industry standard for automotive, medical, aerospace

2. **CERT C Coding Standard**
   - Security-focused coding guidelines

3. **Embedded C Coding Standard (Barr Group)**
   - Practical guidelines for embedded developers

## Books

### Essential Reading

1. **"Making Embedded Systems"** - Elecia White
   - Design patterns for embedded software
   - Practical, accessible writing style

2. **"Embedded Systems Architecture"** - Tammy Noergaard
   - Comprehensive guide to system design
   - Covers hardware-software integration

3. **"The Art of Electronics"** - Horowitz & Hill
   - Bible of electronics design
   - Essential for understanding hardware

### Advanced Topics

4. **"Patterns for Time-Triggered Embedded Systems"** - Michael Pont
   - FSM design, scheduling architectures

5. **"Real-Time Concepts for Embedded Systems"** - Qing Li
   - RTOS theory and practice

6. **"Test-Driven Development for Embedded C"** - James Grenning
   - Unit testing strategies for embedded

7. **"Better C/C++ Coding"** - Pier Paolo Giulieri
   - Modern best practices

### Debugging & Legacy Code

8. **"Debugging"** - David J Agans
   - Systematic debugging methodology

9. **"Working Effectively with Legacy Code"** - Michael Feathers
   - Strategies for improving existing codebases
