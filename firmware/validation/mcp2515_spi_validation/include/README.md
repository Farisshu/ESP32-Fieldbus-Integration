# Include Directory

Project-specific header files for the CAN SPI Test project.

## Purpose

This directory contains header files with:
- Pin definitions
- Register constants
- Function declarations
- Type definitions

## Usage

Include these headers in your source files:

```cpp
#include "pin_defs.h"
#include "mcp2515_regs.h"
```
