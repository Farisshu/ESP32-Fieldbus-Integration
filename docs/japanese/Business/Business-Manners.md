## 1. Introduction / はじめに

### 💡 Key Points / このセクションのポイント

- **Business manners are NOT optional** / ビジネスマナーは**選択肢（せんたくし）ではありません**
- **Essential skill in Japanese workplaces** / 日本（にほん）の職場（しょくば）では必須（ひっす）スキル
- **All interns must use keigo** / 実習生（じっしゅうせい）は全員（ぜんいん）[敬語（けいご）](../Language/Keigo.md) を使（つか）う

### 📊 Why Business Manners Matter / ビジネスマナーが重要（じゅうよう）な理由（りゆう）

In Japanese companies, business manners are fundamental to being seen as a professional.

日本（にほん）の企業（かいしゃ）では、ビジネスマナーはプロフェッショナルとしての基本（きほん）です。

| Element / 要素（ようそ） | Japanese / 日本語（にほんご） | Reading / 読（よ）み方（かた） | Description / 説明（せつめい） |
|----------|----------|---------|-------------|
| Respect / 尊敬 | 尊敬 | そんけい | Respect toward colleagues and company / 同僚（どうりょう）や会社（かいしゃ）への敬意（けいい） |
| Professionalism / プロ意識 | プロ意識 | ぷろいしき | Serious approach to work / 仕事（しごと）への真面目（まじめ）な取（と）り組（く）み |
| Teamwork / チームワーク | 協調性 | きょうちょうせい | Consideration for others / 他（ほか）の人（ひと）への気遣（きづか）い |
| Reliability / 信頼 | 信頼性 | しんらいせい | Trust as a team member / チームメンバーとしての信用（しんよう） |

> **💡 Intern Tip / 実習生（じっしゅうせい）ポイント**: Technical skills are important, but good manners make supervisors think "This person is worth training." / 技術力（ぎじゅつりょく）も大切（たいせつ）ですが、マナーができていることで「この人（ひと）は育（そだ）てがいがある」と思（おも）われます。

## 2. Business Mindset / ビジネスマインドセット

### 💡 Key Points / このセクションのポイント

- **Ho-Ren-So (報・連・相)** is fundamental to Japanese companies / **報・連・相（ほう・れん・そう）** は日本（にほん）企業（かいしゃ）の基本（きほん）
- Punctuality is absolute / 時間厳守（じかんげんしゅ）は絶対（ぜったい）
- Proactive reporting is essential / 自主的（じしゅてき）な報告（ほうこく）が大切（たいせつ）

### 📌 Ho-Ren-So / 報・連・相（ほう・れん・そう）

**Ho-Ren-So** is the foundation of Japanese business communication.

**報・連・相（ほう・れん・そう）** は日本（にほん）のビジネスコミュニケーションの基礎（きそ）です。

| Kanji / 漢字（かんじ） | Reading / 読（よ）み方（かた） | Meaning / 意味（いみ） | Description / 説明（せつめい） |
|----------|---------|---------|-------------|
| 報 | ほう | Report / 報告（ほうこく） | Report progress and results to supervisor / 進捗（しんちょく）や結果（けっか）を上司（じょうし）に伝（つた）える |
| 連 | れん | Contact / 連絡（れんらく） | Share information with stakeholders / 関係者（かんけいしゃ）に情報（じょうほう）を共有（きょうゆう）する |
| 相 | そう | Consult / 相談（そうだん） | Ask supervisor when unsure about decisions / 判断（はんだん）に迷（まよ）ったら上司（じょうし）に聞（き）く |

#### ✅ Correct Ho-Ren-So Examples / 正しい報・連・相（ほう・れん・そう）の例（れい）

```
【Report / 報告（ほうこく）】「CAN バステストを午前中（ごぜんちゅう）に完了（かんりょう）しました」
         "I completed the CAN bus test this morning."
【Contact / 連絡（れんらく）】「明日（あした）午後（ごご）から病院（びょういん）に行（い）きます」
         "I'm going to the hospital tomorrow afternoon."
【Consult / 相談（そうだん）】「このコード変更（へんこう）についてご相談（そうだん）できますか」
         "Can I consult about this code change?"
```

#### ❌ Bad Ho-Ren-So Examples / ダメな報・連・相（ほう・れん・そう）

- Don't report only after finishing even if there are problems / 問題（もんだい）があっても終（お）わるまで報告（ほうこく）しない
- Don't take time off without prior notice / 休（やす）むことを事前（じぜん）に連絡（れんらく）しない
- Don't modify code without permission / 勝手（かって）にコードを変更（へんこう）する

> **💡 HORIBA Internship Tip / ホリバ実習（じっしゅう）ヒント**: Report proactively during morning/evening meetings. / 朝礼（ちょうれい）や夕礼（ゆうれい）で積極的（せっきょくてき）に報告（ほうこく）しましょう。

### 🎯 Important Business Values / 重要（じゅうよう）なビジネス価値（かち）

| Value / 価値（かち） | Japanese / 日本語（にほんご） | Reading / 読（よ）み方（かた） | Description / 説明（せつめい） |
|----------|----------|---------|-------------|
| Punctuality / 時間厳守 | 時間厳守 | じかんげんしゅ | Arrive 5-10 minutes early / 5-10 分前（ぷんまえ）に到着（とうちゃく） |
| Responsibility / 責任感 | 責任感 | せきにんかん | Take ownership of your tasks / 自分（じぶん）の任務（にんむ）を取（と）り組（く）む |
| Proactive Reporting / 自主報告 | 自主的（じしゅてき）な報告（ほうこく） | じしゅてきなほうこく | Report before being asked / 聞（き）かれる前（まえ）に報告（ほうこく） |
| Questions / 質問 | 質問（しつもん）する | しつもんする | Ask when unsure (better than mistakes) / 分（わ）からないときは聞（き）く（ミスより良い（よい）） |
| Teamwork / チームワーク | 協調性 | きょうちょうせい | Prioritize team success / チームの成功（せいこう）を優先（ゆうせん） |
| Humility / 謙虚 | 謙虚（けんきょ）さ | けんきょさ | Accept feedback openly / フィードバックを素直（すなお）に受（う）ける |
| Learning / 学習 | 継続的（けいぞくてき）な学習（がくしゅう） | けいぞくてきながくしゅう | Improve every day / 毎日（まいにち）上達（じょうたつ）する |

### ⚠️ Important Notes / 注意点（ちゅういてん）

> **⚠️ About Punctuality / 時間厳守（じかんげんしゅ）について**: 
> - Arrive at "8:55" not "exactly 9:00" / 「ちょうど 9 時（じ）」ではなく「8 時 55 分（ごじゅうごふん）」に到着（とうちゃく）
> - Contact in advance if you'll be late / 遅刻（ちこく）しそうなら、事前（じぜん）に連絡（れんらく）
> - Be seated 5 minutes before meetings / 会議（かいぎ）は 5 分前（ふんまえ）に着席（ちゃくせき）

## 3. Essential Expressions / 必須（ひっす）ビジネス表現（ひょうげん）

### 💡 Key Points / このセクションのポイント

- Master expressions used daily / 毎日（まいにち）使（つか）う表現（ひょうげん）を完璧（かんぺき）に
- Never use wrong expressions / ❌ 間違った表現（ひょうげん）は絶対に使（つか）わない
- Use correct expressions immediately / ⭕ 正しい表現（ひょうげん）をすぐに使（つか）えるように

### 🔄 Common Substitutions / よくある言（い）い換（か）え

| ❌ Wrong / ダメ | ⭕ Correct / 正しい | Reading / 読（よ）み方（かた） | Reason / 理由（りゆう） |
|--------|---------|---------|-------------|
| 了解（りょうかい）しました | 承知（しょうち）いたしました | しょうちいたしました | 「了解（りょうかい）」is too casual / はカジュアルすぎる |
| わかりました | かしこまりました | かしこまりました | More polite expression / より丁寧（ていねい）な表現（ひょうげん） |
| やっときました | 対応（たいおう）いたしました | たいおういたしました | Professional way to say / プロらしい言（い）い方（かた） |
| これ | こちら | こちら | More polite pointing / より丁寧（ていねい）な指（さ）し方（かた） |
| それ | そちら | そちら | More polite pointing / より丁寧（ていねい）な指（さ）し方（かた） |
| あれ | あちら | あちら | More polite pointing / より丁寧（ていねい）な指（さ）し方（かた） |
| どうして | いかがでしょうか | いかがでしょうか | Polite suggestion / 丁寧（ていねい）な提案（ていあん） |
| ください | いただけますか | いただけますか | More humble request / より謙譲（けんじょう）な依頼（いらい） |

### ⚠️ How to Use "Sumimasen" / 「すみません」の使（つか）い方（かた）

> **💡 Useful Word / 便利（べんり）な言葉（ことば）**: 「すみません」can be used in these situations: / 以下（いか）の状況（じょうきょう）で使（つか）えます：
> - Calling someone / 人（ひと）を呼（よ）ぶとき：「すみません、ちょっと…」
> - Light apology / 軽（かる）い謝罪（しゃざい）: 「すみません、遅（おそ）れました」
> - Instead of thanks / 感謝（かんしゃ）の代（か）わり：「すみません、助（たす）かります」
>
> **⚠️ Warning / 注意（ちゅうい）**: For serious mistakes or customers, use「申し訳（もうしわけ）ございません」. / 重要（じゅうよう）なミスや顧客（こきゃく）には「申し訳（もうしわけ）ございません」を使（つか）ってください。

### 💳 名刺交換（めいしこうかん）

1. **もらう**: 両手（りょうて）で受（う）け取（と）る
2. **確認（かくにん）**: 名前（なまえ）と役職（やくしょく）を確（たし）かめる
