# Keigo (敬語) - Japanese Honorifics Guide

## Pengantar

**Keigo** adalah sistem bahasa hormat dalam bahasa Jepang yang sangat penting untuk lingkungan bisnis dan profesional. Penguasaan keigo menunjukkan respek dan pemahaman budaya Jepang.

---

## 3 Jenis Keigo

### 1. Teineigo (丁寧語) - Polite Language
Bahasa sopan dasar, menggunakan bentuk **〜ます/〜です**.

| Biasa | Teineigo |
|-------|----------|
| 行く (iku) | 行きます (ikimasu) |
| 食べる (taberu) | 食べます (tabemasu) |
| だ (da) | です (desu) |

**Penggunaan**: Situasi umum, dengan orang yang baru dikenal

---

### 2. Sonkeigo (尊敬語) - Respectful Language
**Meninggikan** lawan bicara atau atasan. Digunakan ketika membicarakan **aksi atasan**.

#### Verb Konjugasi Sonkeigo Umum

| Verb Biasa | Sonkeigo | Romaji |
|------------|----------|--------|
| 行く (iku) | いらっしゃる | irassharu |
| 来る (kuru) | いらっしゃる | irassharu |
| いる (iru) | いらっしゃる | irassharu |
| 言う (iu) | おっしゃる | ossharu |
| 見る (miru) | ご覧になる | goran ni naru |
| 会う (au) | お会いになる | oai ni naru |
| する (suru) | なさる | nasaru |
| 食べる (taberu) | 召し上がる | meshiagaru |
| 飲む (nomu) | 召し上がる | meshiagaru |
| 知る (shiru) | ご存知だ | gozonji da |
| 死ぬ (shinu) | お亡くなりになる | onakunari ni naru |

#### Pola Sonkeigo

**A. O + Verb stem + ni naru**
- 読む (yomu) → お読みになる (oyomi ni naru)
- 待つ (matsu) → お待ちになる (omachi ni naru)

**B. Rare form (Serupa pasif)**
- 書く (kaku) → 書かれる (kakareru)
- 話す (hanasu) → 話される (hanasareru)

#### Contoh Kalimat Sonkeigo

✅ **Benar**:
- 部長はもう**いらっしゃいました**か？(Buchō wa mō irasshaimashita ka?) = Apakah manajer sudah datang?
- 社長がそう**おっしゃいました**。(Shachō ga sō osshaimashita) = Presiden direktur berkata demikian.
- 田中さんは会議室に**おります**。(Tanaka-san wa kaigishitsu ni orimasu) = Tanada ada di ruang rapat.

❌ **Salah**:
- ~~部長は来ましたか？~~ (Terlalu langsung untuk atasan)
- ~~社長が言いました~~ (Kurang hormat)

---

### 3. Kenjougo (謙譲語) - Humble Language
**Merendahkan diri sendiri** untuk menghormati lawan bicara. Digunakan ketika membicarakan **aksi sendiri/kelompok sendiri**.

#### Verb Kenjougo Umum

| Verb Biasa | Kenjougo | Romaji |
|------------|----------|--------|
| 行く (iku) | 参る | mairu |
| 来る (kuru) | 参る | mairu |
| いる (iru) | おる | oru |
| 言う (iu) | 申し上げる | mōshiageru |
| 見る (miru) | 拝見する | haiken suru |
| 会う (au) | お目にかかる | ome ni kakaru |
| する (suru) | いたす | itasu |
| 食べる (taberu) | いただく | itadaku |
| 飲む (nomu) | いただく | itadaku |
| 知る (shiru) | 存じる | zonjiru |
| 思う (omou) | 存じる | zonjiru |
| 聞く (kiku) | 伺う | ukagau |
| 訪ねる (tazuneru) | 伺う | ukagau |
| もらう (morau) | いただく | itadaku |
| あげる (ageru) | さしあげる | sashiageru |

#### Pola Kenjougo

**A. O + Verb stem + suru / itasu**
- 連絡する (renraku suru) → ご連絡いたします (gorenraku itashimasu)
- 確認する (kakunin suru) → ご確認いたします (gokakunin itashimasu)

**B. Verb stem + masu (sudah cukup humble dalam konteks)**
- 報告します (hōkoku shimasu) = Saya akan melaporkan

#### Contoh Kalimat Kenjougo

✅ **Benar**:
- 私が**伺います**。(Watashi ga ukagaimasu) = Saya yang akan berkunjung/mendengar.
- 資料を**拝見しました**。(Shiryō o haiken shimashita) = Saya sudah melihat dokumen.
- 明日、東京に**参ります**。(Ashita, Tōkyō ni mairimasu) = Besok saya pergi ke Tokyo.
- ご注文を**承ります**。(Gochūmon o uketamawarimasu) = Kami menerima pesanan Anda.

❌ **Salah**:
- ~~私が行きます~~ (Kurang humble untuk konteks bisnis formal)
- ~~見ました~~ (Terlalu langsung, kurang sopan)

## Perbandingan Langsung

| Situasi | Teineigo | Sonkeigo (Atasan) | Kenjougo (Diri Sendiri) |
|---------|----------|-------------------|------------------------|
| Datang | 来ます (kimasu) | いらっしゃいます (irasshaimasu) | 参ります (mairimasu) |
| Ada | います (imasu) | いらっしゃいます (irasshaimasu) | おります (orimasu) |
| Berkata | 言います (iimasu) | おっしゃいます (osshaimasu) | 申し上げます (mōshiagemasu) |
| Melihat | 見ます (mimasu) | ご覧になります (goran ni narimasu) | 拝見します (haiken shimasu) |
| Makan/Minum | 食べます (tabemasu) | 召し上がります (meshiagarimasu) | いただきます (itadakimasu) |
| Mengetahui | 知っています (shitte imasu) | ご存知です (gozonji desu) | 存じています (zonjite imasu) |
| Melakukan | します (shimasu) | なさいます (nasaimasu) | いたします (itashimasu) |

## Penggunaan dalam Email Bisnis

### Pembuka (Opening)

```
拝啓 (Haikei) - Formal opening
平素は格別のご高配を賜り、厚く御礼申し上げます。
(Heisoku wa kakubetsu no go-kōhai o tamawari, atsuku orei mōshiagemasu)
= Terima kasih atas dukungan Anda selama ini.
```

### Menanyakan Ketersediaan Atasan

```
✅ 部長はご在宅でしょうか？(Buchō wa go-zaitaku deshō ka?)
✅ 社長はお席にお戻りになっていますか？(Shachō wa oseki ni omodori ni natte imasu ka?)
```

### Meminta Sesuatu dari Atasan/Klien

```
✅ ご確認いただけますでしょうか？(Go-kakunin itadakemasu deshō ka?)
✅ ご検討のほど、よろしくお願い申し上げます。(Go-kentō no hodo, yoroshiku onegai mōshiagemasu)
```

### Mengirim Dokumen

```
✅ 資料をお送りいたします。(Shiryō o okuri itashimasu)
✅ 見積書をご送付申し上げます。(Mitsumorisho o sōfu mōshiagemasu)
```

### Menunggu Respon

```
✅ ご返信をお待ちしております。(Go-henshin o omachi shite orimasu)
✅ お返事いただければ幸いです。(Ohenji itadakereba saiwai desu)
```

### Penutup (Closing)

```
敬具 (Keigu) - Formal closing
末筆ながら、貴社の益々のご発展をお祈り申し上げます。
(Matsufude nagara, kisha no masumasu no go-hatten o oinori mōshiagemasu)
= Semoga perusahaan Anda semakin berkembang.
```

## Kesalahan Umum (Common Mistakes)

### ❌ Double Keigo
```
❌ お召し上がりになる (o-meshiagari ni naru) - SALAH!
✅ 召し上がる (meshiagaru) - SUDAH CUKUP
```
"Meshiagaru" sudah sonkeigo, tidak perlu "o-" lagi.

### ❌ Menggunakan Sonkeigo untuk Diri Sendiri
```
❌ 私は部長に会いました (Watashi wa buchō ni aimashita) - Kurang humble
✅ 部長にお目にかかりました (Buchō ni ome ni kakarimashita)
```

### ❌ Menggunakan Kenjougo untuk Atasan
```
❌ 部長が参りました (Buchō ga mairimashita) - SALAH BESAR!
✅ 部長がいらっしゃいました (Buchō ga irasshaimashita)
```

### Exercise 1: Pilih Sonkeigo atau Kenjougo

1. Atasan datang → 部長が______ (kuru)
2. Saya pergi ke klien → 取引先へ______ (iku)
3. Atasan berkata → 社長が______ (iu)
4. Saya melihat dokumen → 書類を______ (miru)
5. Atasan makan siang → 部長が昼食を______ (taberu)
6. Saya menerima hadiah → プレゼントを______ (morau)

## Tips Menguasai Keigo

1. **Dengarkan dulu** - Perhatikan bagaimana senior berbicara
2. **Hafalkan verb transformasi** - Fokus pada 10-15 verb paling umum dulu
3. **Praktek email** - Email lebih forgiving daripada bicara langsung
4. **Jangan overthink** - Lebih baik pakai teineigo daripada salah keigo
5. **Minta feedback** - Minta koreksi dari native speaker
