# Cheat Sheets - Japanese Quick Reference

## Ringkasan Cepat untuk Referensi Harian

---

## 1. Partikel Essential

| Partikel | Fungsi | Contoh |
|----------|--------|--------|
| **は** (wa) | Topik | 私**は**エンジニア (Saya engineer) |
| **が** (ga) | Subjek | 私**が**やります (SAYA yang lakukan) |
| **を** (o) | Objek | コード**を**書く (Menulis kode) |
| **に** (ni) | Waktu/Target | 9 時**に**、東京**に** (Jam 9, ke Tokyo) |
| **で** (de) | Tempat aksi/Metode | 会議室**で**、日本語**で** |
| **と** (to) | Dan/Dengan | 田中さん**と** (Dengan Tanaka) |
| **から** (kara) | Dari | 9 時**から** (Dari jam 9) |
| **まで** (made) | Sampai | 5 時**まで** (Sampai jam 5) |
| **の** (no) | Kepemilikan | 私**の**パソコン (Laptop saya) |
| **へ** (e) | Arah | 日本**へ**行く (Pergi ke Jepang) |

## 2. Konjugasi Kata Kerja Cepat

### Group 1 (Godan) - u → imasu
```
書く (kaku) → 書きます (kakimasu)
話す (hanasu) → 話します (hanashimasu)
待つ (matsu) → 待ちます (machimasu)
飲む (nomu) → 飲みます (nomimasu)
買う (kau) → 買います (kaimasu)
```

### Group 2 (Ichidan) - ru → masu
```
食べる (taberu) → 食べます (tabemasu)
見る (miru) → 見ます (mimasu)
寝る (neru) → 寝ます (nemasu)
```

### Group 3 (Irregular)
```
する (suru) → します (shimasu)
来る (kuru) → 来ます (kimasu)
```

## 3. Bentuk Negatif & Past

| Bentuk | Pola | Contoh |
|--------|------|--------|
| **Negatif** | Verb stem + masen | 書きません (kakimasen) |
| **Past** | Verb ta-form + mashita | 書きました (kakimashita) |
| **Past Neg** | Verb stem + masen deshita | 書きませんでした |

### i-adjective
```
高い (takai) → 高くない (takakunai) → 高かった (takakatta)
```

### na-adjective
```
静か (shizuka) → 静かではない → 静かだった
```

## 4. Te-Form Patterns

### Membuat Te-Form
| Akhiran | Perubahan | Contoh |
|---------|-----------|--------|
| u/tsu/ru | tte | 買う→買って |
| mu/bu/nu | nde | 飲む→飲んで |
| ku | ite | 書く→書いて |
| gu | ide | 泳ぐ→泳いで |
| su | shite | 話す→話して |
| iru/eru | te | 食べる→食べて |

### Pola dengan Te-Form
```
〜てください (te kudasai) = Tolong ...
〜てもいい (te mo ii) = Boleh ...
〜てはいけない (te wa ikenai) = Tidak boleh ...
〜ている (te iru) = Sedang ...
〜てから (te kara) = Setelah ...
```

## 6. Frasa Bisnis Harian

### Greeting
```
おはようございます - Selamat pagi
お疲れ様です - Terima kasih atas kerja keras
お先に失礼します - Permisi pulang dulu
よろしくお願いします - Mohon bantuannya
```

### Email Opening/Closing
```
【Pembuka】
拝啓 (Haikei)
平素は格別のご高配を賜り、厚く御礼申し上げます。

【Penutup】
敬具 (Keigu)
末筆ながら、貴社の益々のご発展をお祈り申し上げます。
```

### Meminta & Mengkonfirmasi
```
ご確認いただけますでしょうか？ = Bisa tolong konfirmasi?
ご検討のほどよろしくお願い申し上げます。 = Mohon pertimbangannya.
お手数をおかけしますが = Mohon maaf atas ketidaknyamanan
念のため確認させていただきます = Izinkan saya konfirmasi untuk memastikan
```

```
1-10: ichi, ni, san, shi/yon, go, roku, shichi/nana, hachi, kyū/ku, jū
100: hyaku
1000: sen
10000: man
```

## 9. Waktu & Tanggal

### Hari
```
月曜日 (getsuyōbi) - Senin
火曜日 (kayōbi) - Selasa
水曜日 (suiyōbi) - Rabu
木曜日 (mokuyōbi) - Kamis
金曜日 (kin'yōbi) - Jumat
土曜日 (doyōbi) - Sabtu
日曜日 (nichiyōbi) - Minggu
```

### Bulan
```
1 月 (ichigatsu) - Januari
2 月 (nigatsu) - Februari
...
12 月 (jūnigatsu) - Desember
```

### Relative Time
```
今日 (kyō) - Hari ini
明日 (ashita) - Besok
昨日 (kinō) - Kemarin
今週 (konshū) - Minggu ini
来週 (raishū) - Minggu depan
先週 (senshū) - Minggu lalu
```

## 10. Emergency Phrases

```
助けて！(Tasukete!) - Tolong!
大丈夫ですか？(Daijōbu desu ka?) - Apakah Anda baik-baik saja?
救急車を呼んで！(Kyūkyūsha o yonde!) - Panggil ambulans!
病院はどこですか？(Byōin wa doko desu ka?) - Di mana rumah sakit?
通訳をお願いします。(Tsūyaku o onegai shimasu) - Tolong panggil penerjemah.
わかりません。(Wakarimasen) - Saya tidak mengerti.
もう一度お願いします。(Mō ichido onegai shimasu) - Sekali lagi mohon.
ゆっくり話してください。(Yukkuri hanashite kudasai) - Tolong bicara pelan.
```

## 12. Checklist Meeting

### Sebelum Meeting
- [ ] 資料を準備する (Shiryō o junbi suru) - Siapkan materi
- [ ] 会議室を予約する (Kaigishitsu o yoyaku suru) - Booking ruang
- [ ] 参加者に通知する (Sankasha ni tsūchi suru) - Notifikasi peserta

### Saat Meeting
- [ ] 議事録を取る (Gijiroku o toru) - Ambil notulen
- [ ] 確認する (Kakunin suru) - Konfirmasi
- [ ] 質問する (Shitsumon suru) - Bertanya

### Setelah Meeting
- [ ] 議事録を送る (Gijiroku o okuru) - Kirim notulen
- [ ] タスクを確認する (Tasuku o kakunin suru) - Konfirmasi tugas
- [ ] フォローアップする (Forō appu suru) - Tindak lanjut
