## 🎯 Learning Path / 学習（がくしゅう）パス

### For Beginners / 初心者（しょきんしゃ）向け

1. Start with **Basic Greetings** - Learn essential daily phrases
2. Study **Ho-Ren-So** - Understand Japanese communication fundamentals
3. Practice **Keigo Basics** - Learn polite business language
4. Review **Engineer Vocabulary** - Build technical terminology

### For Intermediate Learners / 中級者（ちゅうきゅうしゃ）向け

1. Master **Business Expressions** - Professional workplace communication
2. Study **Keigo Mistakes** - Avoid common honorific errors
3. Practice **Engineering Scenarios** - Technical workplace situations
4. Review **Company Etiquette** - Office behavior and customs

### For Advanced Preparation / 上級準備（じょうきゅうじゅんび）

1. Study **HORIBA Internship Tips** - Specific internship guidance
2. Review **Common Mistakes** - Learn from others' errors
3. Practice **Quick Reference** - Memorize essential phrases
4. Prepare **Daily Reports** - Practice progress reporting

## 📖 Key Topics / 重要（じゅうよう）トピック

### Language Levels / 言葉（ことば）のレベル

| Level | Japanese | Reading | When to Use |
|-------|----------|---------|-------------|
| Casual | ため口（ぐち） | tameguchi | Friends, family |
| Polite | 丁寧語（ていねいご） | teineigo | General conversation |
| Business | 敬語（けいご） | keigo | Workplace, supervisors |
| Humble | 謙譲語（けんじょうご） | kenjougo | Talking about yourself |
| Honorific | 尊敬語（そんけいご） | sonkeigo | Talking about superiors |

### Essential Concepts / 必須（ひっす）概念（がいねん）

| Concept | Japanese | Reading | Importance |
|---------|----------|---------|------------|
| Ho-Ren-So | 報・連・相 | hou-ren-sou | ⭐⭐⭐⭐⭐ Foundation of communication |
| Punctuality | 時間厳守（じかんげんしゅ） | jikan genshu | ⭐⭐⭐⭐⭐ Critical for professionalism |
| Teamwork | 協調性（きょうちょうせい） | kyouchousei | ⭐⭐⭐⭐⭐ Essential for harmony |
| Humility | 謙虚（けんきょ）さ | kenkyo-sa | ⭐⭐⭐⭐ Important for learning |

## 📝 Study Tips / 学習（がくしゅう）ヒント

1. **Practice Daily** - Even 15 minutes helps build habits
2. **Use Flashcards** - Apps like Anki for vocabulary retention
3. **Watch Videos** - Japanese engineering YouTube channels
4. **Practice with Colleagues** - Don't fear mistakes
5. **Learn Kanji Gradually** - Focus on common technical characters first
6. **Understand Honorifics** - Critical for workplace communication
